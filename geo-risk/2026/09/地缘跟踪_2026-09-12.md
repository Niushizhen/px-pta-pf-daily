**1. 霍尔木兹仍几近停摆，但红海与外交出现首条缓和通道**

## 一、中东（美伊 / 以色列 / 霍尔木兹 / 红海 / 胡塞 / 沙特）

- **霍尔木兹通行降至个位数**：Kpler/Reuters 9/11称过去24h仅7艘通过（2出5入），较前日12、周中18续降；iransitrep（Day196）口径更极——称仅3%战前水平（6艘/日、2油轮）；流量约1000万桶/日、约为战前一半，燃料产品流量严重受限。
- **外交缓和通道开启**：FT报道海合会六国外长将应阿曼倡议于9/14在塞拉莱与伊朗外长阿拉格齐会晤，推动霍尔木兹临时通行安排（船只经伊朗水域进、主要经阿曼水域出）；中、韩、伊外长亦有接触。美伊无直接对话，但区域调停保持秘密渠道；美方要求新协议须纳入伊核议题，伊方要求解除封锁、恢复石油出口。
- **红海胡塞停火**：胡塞最高政治委员会9/11晚间声明红海西岸各省交火停止，称沙特方面"用于威胁也门有关地区的武装力量已被驱逐"；此前胡塞夺取Mokha港、重创Jazan/Abha储罐。停火性质与可持续性待观察（UN也门特使称也门进入"危险阶段"）。
- **沙特红海能源设施重创**：Hamer卫星9/10证实Jazan炼厂（400kb/d）及Jazan、Abha散装厂多座储罐被毁，73人伤；红海出口侧（对欧非替代通道）承压，或推升欧洲/东非柴油与燃料油裂差。
- **美伊对油轮互袭延续**：美9/8毁5艘伊朗油轮、伊称击中2美舰+8油轮（CENTCOM否认美舰被击）；特朗普称"无后悔"、战事"中选后收场"；WSJ称白宫正考虑正式宣布伊战"结束"、转以制裁+封锁为主，但五角大楼将驻中东兵力延长至2027。

## 二、俄乌战争（俄 / 乌 / 欧盟制裁 / 能源管道 / 天然气与原油）

- **乌9/11夜扩大炼油打击**：萨拉托夫炼厂（Rosneft，第16次被袭）、Ozon物流仓起火；伏尔加格勒Lukoil炼厂、彼尔姆"Azot"化工（硝酸铵/炸药原料，俄唯一硝酸钠产商）被袭；卡斯皮斯克港、萨马拉亦中弹（RBC-Ukraine、Tverezo）。
- **亚马尔天然气设施首遭**：9/9 FP-1无人机飞3200km袭新乌连戈伊+普罗夫斯基（俄约80%天然气产区），欧洲TTF升至82欧（三年高）；IEA称制裁+精准打击致俄炼厂故障累积、临时维修难消旧损。
- **俄产量低于配额**：OPEC月报（Bloomberg）俄8月产8.718 mb/d，较OPEC配额低117万桶/日，为2025年12月以来最低——乌袭炼油+出口终端迫使炼厂降负荷、产量被动缩减。
- **俄反击与民用能源**：基辅1死14伤、敖德萨2死3伤、索契水上无人机8伤；双方能源基础设施互袭加剧，入冬前局部燃料/供暖短缺与修复周期拉长风险上升。
- **欧盟制裁走向**：拟第22轮制裁封Yamal LNG 14艘Arc7油轮；欧盟2027.1.1起禁止俄LNG进口（REPowerEU），但8月俄LNG进口环比-46%至战期最低、收入反升18%。

## 三、美国（对外政策 / 制裁 / 涉能源 / 对华）

- **"经济弃儿行动"（Operation Economic Outcast）**：OFAC 9/4制裁土耳其Golden Global Bank（涉IRGC圣城旅、为中国购伊油提供清算）；9/9对伊朗特定许可改为"推定拒绝"（关闭多数个案审批通道）；9/8无限期中止3项通用许可（含民航临时过境GL J-1）；SDN持续更新（伊朗/反恐/古巴）。
- **委内瑞拉与电力**：9/2修订GL 51D/54C/55A放宽煤炭/矿产/黄金交易；EO 14420（8/26）宣布"保障美国大电力系统"国家紧急状态；美据报推进委"百年油约"但设施修复需数年。
- **燃料价格纪录**：美柴油创历史高位（GasBuddy 9/10全美均值首破6美元/加仑；Srpske称周五约5.94并续升），汽油均价4.22美元/加仑（+32% yoy）；JPMorgan预计年内8-9家发达央行加息。
- **对华**：中国就美制裁涉伊中企表态反对；美据报拟扩大对土耳其/印度/中国涉伊油结算的二级制裁，Golden Global Bank案直指"中国采购伊朗油"清算链。

## 四、中国（外交 / 台海 / 南海 / 对俄伊立场 / 能源安全）

- **能源安全与成品油调价**：发改委9/12起上调汽油、柴油零售限价260/250元/吨（呼应油价飙升）；中国战略储备约12.3亿桶（维基2026口径）、约115-120天进口量，危机以来基本未动、以商业库存消化，缓冲显著；3-7月原油进口同比-23%，挺价且隔离外部冲击。
- **台海**：ISW 9/11称中国海警延续每月"执法巡逻"常态化部署台湾东部海域（9/4新一对轮换），向阳红03科考船在台东测绘（反潜/水下战意图，疑首见海警+海上民兵护航）；台湾行政院追加1457亿新台币（约46亿美元）无人系统特别预算。
- **对俄伊**：中国为俄原油第一大买家（占俄出口约51%）、伊朗油经影子船队折价入华；美制裁Golden Global Bank直指"中国采购伊朗油"清算，中方反对并将经贸与制裁挂钩。
- **南海/马六甲**：美专家"封锁台海+马六甲半年逼中国弃武统"论调流出（今日头条），中方以陆上通道（中俄管线、中缅油气、瓜达尔）与战略储备对冲，降低对马六甲单一 chokepoint 依赖。

## 五、东北亚（朝鲜 / 韩国 / 日本 / 美日韩同盟）

## 六、欧盟（对俄 / 对伊 / 对华 / 储气与能源转型 / 内部政治）

- **气价与储气**：TTF 9/11约82欧元/兆瓦时（三年高，年内+147%）；GIE 9/9储气67.3%、低于五年均值约17-20个百分点、远低于11/1的90%目标；National Gas称若注入延续、10/1或达74%，但仍处历史低位。
- **俄气两难**：欧盟8月俄LNG进口环比-46%至战期最低，但俄LNG/管道收入反升18%/25%（量价齐升）；法国占欧盟俄LNG进口57%、西/荷/比跟进；2027.1.1起俄LNG进口非法，倒逼更依赖灵活LNG与亚洲争抢 cargo。
