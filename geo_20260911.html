一、中东（美伊 / 以色列 / 霍尔木兹 / 红海 / 胡塞 / 沙特）

  • 美伊“油轮对油轮”政策延续：CENTCOM称9/8摧毁5艘伊朗油轮（哈尔克岛外），伊革命卫队宣称击中2美舰+8油轮+10“不合规船只”，CENTCOM否认美舰被击；伊朗宣布“波斯湾禁区”并设海上限制区（自恰巴哈尔延伸至阿曼湾/阿拉伯海），已拉黑57艘船只。
  • 霍尔木兹通行极低且剧烈波动：The National 9/10报道“实际近乎关闭”，常规2000万桶/日运力降至约1000万桶/日；UANI称美封锁以来仅约5艘LPG小船通过，无满载伊朗原油油轮成功离港。
  • 红海双线钳制：胡塞夺取曼德北口Mokha港（9/3–6最大规模地面战之一，据报双方阵亡300+），Jizan炼厂（约40万桶/日）持续燃烧；沙特改道地中海出口，MEG–中国VLCC运费一度报76万美元/日创纪录。
  • 以色列报复窗口：犹太新年Rosh Hashanah（9/11–13）临近，以方此前称将打击伊朗“全部能源设施”；美防长与伊朗议长互放狠话，短期缓和概率低。
  • 沙特减产：OPEC月报证实沙特8月日产623.8万桶（-190万桶），创1990以来最低；伊朗暂停对外籍船10%油气运输附加费以降低成本、维系承运意愿。

二、俄乌战争（俄 / 乌 / 欧盟制裁 / 能源管道 / 天然气与原油）

  • 乌克兰远程打击创纪录：9/9 FP-1无人机3200km袭新乌连戈伊凝析油处理厂（GCTP，年处理1950万吨）与普罗夫斯基厂，俄地方政府证实起火；该节点距Yamal LNG 600km，被视为“战火抵北极气核心”。
  • 俄方反制与黑海：俄9/9袭新罗西斯克燃油码头（储罐起火）与黑海舰队基地；恢复对基辅喷气无人机袭击（9/9造成1死17伤）；泽连斯基“停袭能源”提议被普京拒绝，特朗普–普京“良好通话”释放会晤信号。
  • 欧盟制裁走向：拟第22轮制裁将支撑Yamal LNG的14艘Arc7油轮纳入、堵海事/维护制裁漏洞；俄国内燃油危机持续（汽油出口禁至2027.1、炼厂检修约0.35Mt/日）。
  • 黑海粮道：港口运油轮受袭致粮道受阻约4000万吨，保险与改道成本抬升。

三、美国（对外政策 / 制裁 / 涉能源 / 对华）

  • 贸易摩擦：加拿大对美C$27.6B反制关税9/8生效（钢/乳/农机/纸/电子，税率15–50%），特朗普威胁对加汽车/钢加征至50%；美对进口无人机100%关税已生效。
  • G20：8/31–9/1财长会19国背书“非市场政策”措辞，中国否决共识；中美AI安全对话筹备中。
