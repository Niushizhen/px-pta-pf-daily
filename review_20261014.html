一、今日主线（一句话）

地缘断供主线未变、但定价锚发生关键位移——涨幅榜从"原油金融盘"切换到"进口依赖度高的实货品种"（燃料油 +3.3%、MEG +3.3%、纯苯 +2.3%、苯乙烯 +1.2%），原油本身获利回吐（-1.2%）；同时负反馈开关继续在"国内过剩端"兑现（纯碱 -3.2% 领跌、沥青 -2.5%），板块进入"进口断供 vs 国内过剩"的极致分化，两个开关仍在背离运行。

二、技术面复盘（昨收 → 今收）

今日真正值得写的是 3 个结构变化，其余看梯队表。

1. MEG 逆势大涨 +3.3%（收约 5300），是本轮最大预期差：昨收 5135 → 今收约 5300，一举收复 5150 关键位。驱动不在国内供需（国内仍是累库预期），而在中东货源发运受限 + 华东主港库存历史低位——8 月我国乙二醇进口仅 11.74 万吨、同比 -80.15%，进口依赖度极高，地缘断供对它是直接供应利多，而非我昨日框架里的"累库转弱品种"。 2. 油品链内部分化：燃料油续冲 vs 原油获利回吐：燃料油 FU +3.3%（收约 5494）继续走强，低硫燃油 LU 亦强；但原油 SC -1.2% 回落（三连涨后获利了结）。"原油（金融总盘子）弱 vs 成品油/重油（实货缺）强"是油品链新的结构信号。 3. 甲醇"期货企稳、现货续跌"的背离（收 3473，约平）：昨收 3478 → 今收 3473，期货盘面在 3500 下方企稳（前期跌幅已大 + 基差修复）；但现货继续暴跌——太仓 -230 至 3845、内蒙北线 -185、河南 -290、河北 -450，太仓基差 392（-147）大幅回落。更关键的是累库拐点确认：港口库存 +6.21 万吨至 36.72 万吨、企业库存 +3.46 万吨至 35.69 万吨，这是 10 月以来港口库存首次显著累库。

强弱梯队（真实单日强弱）

  • 第一梯队（强）：燃料油、乙二醇、纯苯、苯乙烯 —— 进口断供 + 低库存 + 地缘成本传导
  • 第二梯队（平）：PVC、PP、PE、甲醇、PTA、PX、玻璃 —— 成本支撑 vs 需求弱/新产能压制
  • 第三梯队（弱）：原油（获利回吐）、短纤、瓶片、焦煤、沥青、纯碱 —— 需求负反馈 / 复产 / 供应过剩

技术面要点：与昨日"油品强 vs 煤化工弱"的单一切换不同，今日强弱分野进一步细化——涨的品种共性从"跟原油"变成了"进口依赖度高/实货紧"（燃料油、MEG、纯苯、苯乙烯都是中东或海外货源高依赖品种），跌的品种共性从"需求弱"变成了"国内供给过剩或复产"（纯碱、沥青、短纤、瓶片、焦煤）。原油本身反而因获利了结回落，说明"地缘溢价"正在从"原油金融定价"向"实货断供定价"迁移。

三、基本面驱动（当日利多利空）

利多

1. 地缘持续升级：伊朗对霍尔木兹海峡过往船只袭击激增，威胁波斯湾石油出口复苏势头；胡塞武装警告"沙特阿美旗下石油设施将成为合法打击目标"；沙特周二又拦截多枚胡塞导弹/无人机。 2. 亚洲燃料油实货趋紧：中东装船受阻 + 俄罗斯货源缺位，燃料油可交付资源紧张；LNG 短缺继续提振部分公用事业燃料油需求。 3. MEG 供应断供逻辑：中东货源发运受限 + 华东主港库存历史低位，8 月进口 11.74 万吨、同比 -80.15%；进口依赖度极高，地缘断供直接利多。 4. 纯苯/苯乙烯低库存：纯苯低库存 + 地缘加持（最贴原油成本）；苯乙烯低库存 + 低估值，现货货源偏紧、基差坚挺。 5. 柴油裂解利润高位：原油今年累计涨逾 70%，成品油裂解价差仍处高位，柴油偏强。

利空

1. 俄罗斯柴油协议 + 供应缓和预期：OFAC 临时放松俄柴油制裁（有效期至 2027 年 4 月）+ 美俄柴油协议，市场预期释放更多俄供应，压制原油/柴油。 2. 甲醇累库拐点确认：港口库存 +6.21 万吨至 36.72 万吨（华南 +9.37、华东 -3.16），企业库存 +3.46 万吨至 35.69 万吨；MTO 集中停车（渤化/联泓 10/10 停、富德 9/19 停、恒通 9/18 停，鲁西/兴兴/斯尔邦持续停），诚志停车预期待兑现。 3. 纯碱供应过剩：行业库存高位 + 玻璃产线冷修预期削弱重碱需求，纯碱 -3.2% 领跌能化。 4. 沥青复产 + 需求转弱：北方道路施工收尾 + 主营炼厂增产，沥青 -2.5%。 5. 黑色系/焦煤回调：钢厂利润历史低位 + 铁水产量见顶回落 + 旺季成色不足，焦煤/焦炭跌幅居前。 6. 原油获利了结：三连涨后交易员获利了结，市场缺乏重大事态进展下借机调仓。

五、产业链利润传导（五链一句话）

  • 油品链：原油回落（获利了结）vs 燃料油/低硫燃油续冲（实货紧）。成品裂解价差高位、柴油裂解强，俄罗斯柴油协议暂未实质落地。沥青走弱（复产 + 施工收尾）。→ 利润从"原油金融盘"向"实货紧缺的成品油/重油"集中，沥青仍是油品链最弱环节。
  • 芳烃链：纯苯/苯乙烯强（低库存 + 地缘成本），PX/PTA 横盘偏弱，短纤/瓶片领跌（需求弱 + 新产能）。PTA 加工费被动承压，聚酯端深度亏损未解。→ 利润向"芳烃原料端（纯苯/苯乙烯）"集中，聚酯链（PX/PTA/短纤/瓶片）最弱。
  • 烯烃链：甲醇现货续跌 → MTO 亏损边际修复（仍深亏），PP/PE 靠低库存 + 原油成本微涨。→ 利润从甲醇（上游）向 MTO（下游）修复的早期信号延续，但 MTO 仍深度倒挂。
  • 建材链：纯碱 -3.2% 领跌（过剩 + 高库存 + 玻璃冷修），玻璃微跌，PVC 逆势微涨（偏抗跌但独立于地缘），走地产弱现实。→ 建材链利润仍被地产弱势压制，纯碱最弱。
  • 煤化工：MEG 大涨（中东断供 → 进口依赖度高）vs 焦煤回调（钢厂利润低 + 铁水见顶）。→ 煤化工内部极致分化，定价锚完全相反：MEG 看海外供应、焦煤看国内地产/钢厂。
