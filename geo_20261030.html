综合风险评级：高。当日主线为"美伊外交回暖"与"供给端再遭实质冲击"并存：万斯致信伊朗高层试探重启谈判令油价小幅回落，但胡塞宣称以6枚导弹/无人机打击沙特拉斯塔努拉炼厂等核心设施、IRGC称三艘油轮在霍尔木兹触雷起火，叠加欧洲TTF气价近四年来首破100欧元、朝鲜年内第17次射弹，能源风险溢价底部坚实、无确定性下行拐点。

一句话总结：美伊外交出现缓和信号（万斯致信雷扎伊）压低油价，但胡塞六袭沙特核心炼厂/机场、霍尔木兹再现油轮触雷（IRGC称三艘起火）与欧洲TTF气价破100欧元，令能源供给风险溢价再上台阶；俄乌第聂伯罗火车站袭击14死与人道停火并存的悖论延续，地缘底部仍坚实。

今日要点

1. 霍尔木兹再现油轮触雷，IRGC 称三艘起火、与美国"已扫雷"说法直接矛盾

IRGC 10/30 声明，过去24小时三艘"违规"油轮在霍尔木兹南部非授权航道触雷爆炸起火，美方此前坚称已清除主航道水雷。这是继10/27伊方报一艘油轮东部触雷后，水雷战再度升级，封锁从"骚扰/设障"转向实质破坏。独立数据仍近关闭（IMF PortWatch 7日均线约3%战前、0.9艘/日），逾50艘滞留湾内。

  • 【S 战略级 · ↑ 推涨 · ★★★★★】
  • 关联品种：Brent / WTI、VLCC 运费、PX / MEG / 原油链

2. 胡塞六袭沙特核心能源设施，拉斯塔努拉炼厂列入打击清单

胡塞10/29宣称以导弹/无人机对沙特发动6次打击：东部省拉斯塔努拉炼厂、布盖格阿美设施、红海沿岸拉比格炼厂，利雅得哈立德国王机场（导弹）、达曼法赫德国王机场（无人机）及奈季兰军事指挥所。沙特主导多国联军称拦截3枚弹道导弹（2枚飞向利雅得、1枚飞向东省），利雅得市区落残骸致1名公民轻伤。拉斯塔努拉为阿美最关键出口/炼化枢纽之一，若确认实质损毁可短期抽离数十万至逾百万桶/日产能；目前仅为胡塞单方宣称，沙方未确认运营中断。

  • 【A 高 · ↑ 推涨 · ★★★★★】
  • 关联品种：Brent、汽油 / 柴油 / 航煤、沙特 CDS

3. 美伊外交回暖 vs 战事升级风险并存：万斯致信雷扎伊试探重启谈判

路透/WSJ/纽时披露，副总统万斯经卡塔尔斡旋致信伊朗最高国安委秘书雷扎伊（曾任革命卫队总司令），提议尽快安排直接谈判、由万斯牵头，核计划须纳入议程；以"七日内重开霍尔木兹换制裁松绑"为框架。伊朗称信件"反应积极"、雷扎伊拟周四（10/30）答复；阿拉格齐称仍与调停方密切接触。但特朗普10/28淡化称"仅运送医疗物资"，且 WSJ 称白宫已警告海湾盟友为11/3中期选举后"短促猛烈"军事行动做准备——缓和信号与升级预案同步悬顶。

  • 【A 高 · → 中性 · ★★★★】
  • 关联品种：Brent、黄金、海运保费

4. 朝鲜元山射约10–12枚短程弹道导弹，年内第17次

韩联参10/29确认，朝鲜自江原道元山一带向东部海域发射约10–12枚短程弹道导弹（约250km，疑似 KN-25 超大型火箭炮+混合齐射），为本月12日以来时隔17天再射、年内第17次。背景为金正恩访华后、韩方提议军方会谈遭拒、DMZ地雷事件（3名韩兵受伤）紧张延续。美日韩共享情报、提升戒备；中方外交部称"望有关方为维护地区和平稳定作出努力"。无即时能源供给冲击，但东北亚风险基线抬升。

  • 【B 中 · → 中性 · ★★★】
  • 关联品种：避险资产、黄金

5. 俄乌能源战与外交悖论：第聂伯罗火车站14死，奥列什基人道停火持续

俄10/29以喷气动力无人机击中第聂伯罗火车站站台（一列通勤/客运列车停靠），至少14死14伤，另切尔尼戈夫2名少女、克列缅丘格3人共5死；泽连斯基斥俄"蓄意猎杀平民"并批评美方对俄柴油制裁松绑。与此同时，美方斡旋的奥列什基（赫尔松）6天局部人道停火进入第3天、双方确认无违规；阿布扎比三方（乌俄美）会谈拟11/6–10举行。俄燃料短缺缓解（15地区解除限购），但铁路/能源基础设施战持续。

6. 欧洲 TTF 气价近四年首破100欧元，储气创2011来同期最低

ICE 数据显示，TTF 11月期货10/28盘中突破 €100/MWh（高见 €100.75），为2022年12月以来首次，当日涨约4%、本月累涨约40%；10/29回落至约 €98.96。GIE 数据，截至10/28欧盟储气率仅74.96%，创2011年有统计以来同期最低（同比低8个百分点、较五年均低14.6%）；德国约60–61.7%、荷兰65.5%。中东战事扰乱海湾LNG出口，卡塔尔能源对意大利 Adriatic 终端不可抗力延至年底（38船约50亿方受影响），美LNG占欧盟供给约30%。欧盟能源部长10/29开会评估，委员称局势"非常严峻"。

分区域事件与影响

中东（霍尔木兹 / 伊朗 / 以色列 / 沙特 / 也门 / 红海）

  • 霍尔木兹水雷战再升级：IRGC 10/30 称三艘违规油轮在南部非授权航道触雷爆炸起火，直接反驳美军"已扫雷开通主航道"说法；10/27伊方亦报一艘油轮东部触雷。ANZ 称海湾原油出口连降四周，逾50艘滞留湾内。
  • 胡塞–沙特互袭陡升：胡塞10/29单次行动清单涵盖拉斯塔努拉炼厂、布盖格阿美、拉比格炼厂（红海）、利雅得哈立德国王机场、达曼法赫德国王机场、奈季兰指挥所；沙特拦截3枚弹道导弹、市区残骸轻伤1人。胡塞称回应沙特近期对也门空袭（含妇女儿童伤亡），沙特24h内对也门发动百次以上空袭。拉比格/拉斯塔努拉均属阿美核心枢纽，2019年阿布盖格–胡赖斯遇袭曾令布伦特单日飙升约15%，市场即时计入尾部风险溢价。
  • 美伊谈判窗口与升级预案并存：万斯致信雷扎伊（经卡塔尔，周日送达）试探重启谈判、核计划须纳入；伊朗反应积极、雷扎伊拟10/30答复。卡塔尔近期另递交"七日停火"新草案（多国担保）。但伊朗坚持七项条件（解除制裁、解冻资产、结束各战线战争含黎巴嫩停火）满足前不重开霍尔木兹；阿拉格齐10/29称仍与调停方密切接触。特朗普淡化信件为"医疗援助"，WSJ 称白宫已提示海湾盟友为11/3中选后"短促猛烈"行动备豫，部分民主党议员称打击方案"疯狂"。
  • 以色列选举悬峙推升选后袭伊风险：10/28以议会选举计票显示内塔尼亚胡阵营约53席、反对派约67席（约89.8%计票），距61席多数尚远、组阁未定；NYT 此前称美以已拟选后短期高强度打击预案（炼油厂或豁免以稳油价），卡茨否认选前动手。选后政治真空叠加美"中选后再行动"基调，构成11月上行风险扳机。

俄乌（能源战 / 停火 / 谈判）

  • 第聂伯罗火车站袭击：俄喷气动力无人机10/29晨击中第聂伯罗主站站台，至少14死14伤，乌克兰铁路称一列通勤/客运列车停靠时遇袭；同日切尔尼戈夫市中心2名15岁少女等、克列缅丘格住宅楼共5死。泽连斯基斥"恐怖袭击"，并再次批评美方本月对俄柴油制裁松绑"未降级反而助长"。
  • 局部人道停火续存：美方斡旋的奥列什基（赫尔松，俄占）6天停火进入第3天，俄乌人权监察员均确认无违规、扫雷完成，人道援助与居民撤离启动。但该停火仅限局部，全国范围能源/铁路基础设施战延续。
  • 三方会谈拟启：泽连斯基称乌俄美希望11/6–10在阿布扎比会晤；乌方呼吁欧洲参与以保持盟友团结。俄方此前原则同意11月中旬重启俄美乌三方会谈，但立场未变、能源互袭未停。
  • 俄燃料短缺缓解：俄国内燃料限购在15个地区解除，但铁路与炼化设施仍持续遭乌远程打击，柴油出口禁令走向待观察。

美国（对外政策 / 制裁 / 涉伊 / 中选）

  • 万斯信道伊朗：副总统绕过常规渠道直联雷扎伊，反映华府判断"能同时影响强硬派与革命卫队"的实权人物才是谈判支点；万斯历来对开战持怀疑态度，其回归谈判被视为外交未弃信号。
  • 特朗普双轨基调：一边淡化信件、称聚焦医疗物资与"运送帮助"，一边保留选后军事选项；WSJ 称白宫警告海湾盟友备战"短促猛烈"行动。中选（11/3）为关键时间锚——缓和或升级均大概率落在选后。
  • 军事部署：特朗普拟听取 CENTCOM "短促猛烈"打击+霍尔木兹管控方案汇报，并申请部署"暗鹰"高超音速导弹至中东，以强化封锁/威慑能力。

中国（外交 / 台海 / 南海 / 能源安全）

  • 国防部10/29记者会：就台海、南海及菲日美联合演习等答问，重申一个中国原则与南海主权主张，对域外势力介入表达关切；区域摩擦维持常态、未升级为供给直接扰动。
  • 外交部回应朝鲜射弹：发言人郭嘉昆称"注意到有关方面对发射物界定存在不同看法"，望有关方正视半岛问题根源、坚持政治解决大方向、维护地区和平稳定。
  • 能源安全立场：作为伊朗原油最大买家与潜在调停担保方（AOL 提及中方或担任美伊履约第三方担保），在美伊"七条件/核库存外运" sequencing 争议中角色关键；国内能化价格受外盘战争溢价传导明显。

东北亚（朝鲜 / 韩国 / 日本 / 美日韩同盟）

  • 朝鲜第17次射弹：元山约10–12枚 SRBM（约250km，疑 KN-25），年内第17次、本月第2次；金正恩访华（一年多来第二次）后紧接试射，向美传递"边对话边试武"信号。特朗普此前调低与金会面预期。
  • 美日韩戒备：三方共享情报、加强监视，保持万全态势；韩方提议的军方会谈遭朝拒绝。该窗口暂无新增试射确认，但基线紧张延续。

欧盟（对俄 / 对伊 / 天然气储备 / 内部政治）

  • TTF 破百、储气历史低位：10/28 TTF 11月期货盘中 €100.75（2022/12来首破），10/29回落约 €98.96；Platts 次月评估上次破百为2022/12/20。EU 储气74.96%（GIE，2011来同期最低），德约60–61.7%、荷65.5%，注气近月几近平线。
  • LNG 断供与替代：中东战事致海湾LNG出口受阻，卡塔尔能源对意大利 Adriatic 终端不可抗力延至年底（38船约50亿方），夏季几乎无卡塔尔LNG抵欧、EU夏季LNG进口同比-14%；美LNG填补约30%供给。
  • 政策应对：欧盟能源部长10/29开会评估能源安全，委员称"非常严峻"、可负担性同为紧迫问题；欧委会10/28起与炼厂谈扩产，西方本月同意释放逾4亿桶应急油储。
  • 俄气禁令法律化：REPowerEU 分阶段禁俄气（长期LNG 2027/1/1、管道2027/9/30）推进；普京10/27气出口国论坛批评欧洲能源政策。
